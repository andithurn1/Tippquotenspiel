# Screenshots — so zeigt Andi, wie er es haben will

**Angelegt 09.08.2026.** Beschreiben ist mühsam und ungenau; ein Bild ist in
zwei Sekunden gemacht. Hier landen Vorlagen, Skizzen und Vorher/Nachher-Belege.

## Ablegen

Einfach die Datei in diesen Ordner legen. **PNG oder JPG** — beides kann ich
direkt ansehen. Kein PDF: der Renderer fehlt auf diesem Rechner, und ein
Canva-PDF ist innen ein Haufen roher Bitmaps (steht in `CLAUDE.md` bei den
Werkzeug-Fallen).

## Benennen

```
<screen>-<was>.png
```

Beispiele:

| Datei | meint |
|---|---|
| `erstellen-soll.png` | so soll die Spielerstellung aussehen |
| `erstellen-ist.png` | so sieht sie jetzt aus (was stört) |
| `vorbild-app-xy.png` | fremde App, deren Gestaltung als Vorbild dient |
| `tippen-kopfzeile.png` | Ausschnitt, nur um eine Stelle zu zeigen |

Der Screen-Teil ist der Pfad in der App ohne Schrägstrich: `erstellen`,
`tippen`, `ranking`, `menu`, `stil`. Wenn es um kein bestimmtes Fenster geht:
`vorbild-…` oder `allgemein-…`.

⚠️ **Ein Satz dazu in den Chat gehört trotzdem hin.** Ein Bild zeigt, WAS —
selten WARUM. „So, aber die Kacheln kleiner" ist die Hälfte der Information,
die ein Bild allein nicht trägt.

## Warum im Repo und nicht nur im Chat

Ein Chatverlauf ist nach dem Fenster weg. Was hier liegt, sieht jede spätere
Sitzung — und die zweite Session am selben Repo auch. Dieselbe Begründung wie
bei `design/*.md`: **Befunde ins Repo, nicht in den Chat.**

⚠️ Screenshots von echten Nutzerdaten (Mailadressen, Namen von Mitspielern)
vorher schwärzen. Das Repo liegt auf GitHub.
